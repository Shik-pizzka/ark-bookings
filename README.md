# Ark bookings

Страница просмотра бронирований ресторана для тестового задания Ark Studio.

## Что реализовано

- Vue 3 + Vite.
- Переключение даты просмотра.
- Включение и отключение зон ресторана.
- Фиксированный заголовок со столами и фиксированная колонка времени.
- Отображение текущего времени ресторана по `Asia/Vladivostok`.
- Отображение заказов, банкетов, бронирований, заявок и живой очереди.
- Разведение пересекающихся событий по внутренним дорожкам без наложений.
- Hover-состояние с подробной информацией по событию.
- Поиск по гостю, столу, зоне и статусу.
- Переключение тёмной и светлой темы.
- Скрытие персональных данных.
- Выделение столов и временного диапазона с выводом результата в консоль.
- Unit-тесты для времени, данных и расчёта расположения событий.

Данные подготовлены локально по структуре ответа `/api/booking` из задания.

## Запуск

Требования:


```bash
npm install
npm run dev
```

Проверка:

```bash
npm run test
npm run build
```
